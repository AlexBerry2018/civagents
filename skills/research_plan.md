# Skill: research_plan (Выбрать технологию)

**Роль:** science, single. **Вход:** доступные технологии (`state.research_options`), текущее исследование.
**Процедура:** если текущее исследование входит в первые 7 технологий проверенного порядка ранней игры (Bronze Working, Alphabet, Ceremonial Burial, Pottery, Writing, Code of Laws, Monarchy) — «продолжать». Иначе — первая доступная технология из порядка.
**Выход:** подсказка «research <tech>». Повторный выбор текущего исследования запрещён исполнителем (сбрасывает колбы).
