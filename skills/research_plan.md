# Skill research_plan — what to research (Выбрать технологию)

Used by: science, single. Input: technologies available now and the current research.
How it works: if the current research is one of the first seven techs of the proven early order (Bronze Working, Alphabet, Ceremonial Burial, Pottery, Writing, Code of Laws, Monarchy), keep it. Otherwise suggest the first available tech from that order.
Important: never re-select the technology that is already being researched - it resets the accumulated bulbs. The executor blocks such repeats.
The hint appears as "[research_plan] ...".
