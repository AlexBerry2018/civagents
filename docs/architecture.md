# Архитектура проекта

Агент-«правитель» для Freeciv: мультиагентная система на локальной LLM,
взаимодействующая с игрой через CivRealm.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `src/civ_agents/llm/` | Доступ к языковой модели: общий интерфейс, клиент OpenAI-совместимого API, ретраи, таймауты |
| `src/civ_agents/env/` | Обёртка над CivRealm: состояние игры → компактная сводка, проверка и отправка действий |
| `src/civ_agents/agents/` | Агенты: правитель, советники, исполнитель |
| `src/civ_agents/tools/` | Инструменты (скиллы) агентов поверх API игры |
| `src/civ_agents/memory/` | Память: краткосрочная, эпизодическая, семантическая |
| `src/civ_agents/observability/` | Логи, метрики, трейсы |
| `src/civ_agents/evals/` | Оценка качества: уровень LLM и уровень системы |
| `configs/` | Настройки системы и конфиги CivRealm (в git) |
| `skills/` | Описания скиллов в Markdown |
| `docs/` | Документация, замеры, архитектурные решения (ADR) |
| `tests/` | Тесты |
| `runs/` | Результаты и логи прогонов (не в git) |

## Внешние компоненты

| Компонент | Где работает | Роль |
|---|---|---|
| Сервер Freeciv (freeciv-web) | Docker-контейнер CivRealm, порт 8080 | Игровой сервер |
| Ollama | Docker-контейнер (`compose.yaml`), порт 11434 | Сервер локальной LLM |
| CivRealm | Python-пакет в окружении проекта | Клиент игры: состояние и действия |

## Принципы

- Слой модели отделён от конкретного сервера: модель меняется через конфиг.
- Исполнитель — детерминированный код, а не LLM: проверяет допустимость
  действий перед отправкой в игру.
- Длина партии задаётся на стороне агента (горизонт N ходов), см. ADR 0001.
