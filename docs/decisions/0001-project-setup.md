# ADR 0001. Окружение проекта и интеграция с Freeciv

## Контекст

Нужна воспроизводимая среда разработки на Python для LLM-агента, играющего
во Freeciv. Разработка на Windows через WSL2. Игровая среда — CivRealm
(исследовательский проект BIGAI, 2023–2024), сервер — freeciv-web в Docker.

## Решения

### Инструменты и структура
- **uv** для окружения и зависимостей: быстрее pip/Poetry, единый
  `pyproject.toml` + `uv.lock` для точной воспроизводимости.
- **src-раскладка** (`src/civ_agents/`): тесты импортируют установленный
  пакет, ошибки импорта видны сразу.
- Проект в файловой системе WSL (`~/`), а не на `/mnt/c` — скорость и
  корректная работа Docker.

### Python 3.10 и закреплённые версии
CivRealm и его зависимости не работают на свежих версиях Python и библиотек:
- **Python 3.10**: на 3.14 не ставится `ray`, которого требует CivRealm.
- **`ray`** добавлен явно: CivRealm импортирует его, но не ставит.
- **`setuptools<81`**: старый `ray` использует модуль `pkg_resources`,
  удалённый из новых `setuptools`.
- **`gymnasium<1.0`**: CivRealm использует API обёрток, помеченный
  устаревшим и удаляемый в gymnasium 1.0.

### Интеграция с Freeciv через CivRealm
Альтернативы: прямой протокол freeciv-web (JSON по WebSocket) — дороже
в разработке; нативный протокол сервера — непропорционально сложен.
CivRealm даёт Gym-интерфейс, готовые мини-игры и LLM-обёртку.

## Находки при проверке

- Партия завершается в трёх случаях: игрок разгромлен (`E_DESTROYED`),
  сервер прислал `E_GAME_END`, или сообщение сервера содержит
  «game is over» / «game ended».
- Тестовые партии завершались на ~90-м ходу сообщением сервера
  «The game is over», независимо от `max_turns: 1000` в конфиге CivRealm.
  Ни CivRealm, ни файлы настроек сервера `endturn` явно не задают.
- `terminated` (конец по правилам) и `truncated` (обрыв: таймаут или ошибка
  сервера) различаются; обрывы в evals учитываются отдельно.
- Недопустимая команда (`E_BAD_COMMAND`) приводит к исключению и падению
  партии.
- Логи CivRealm по умолчанию пишутся в `.venv/lib/python3.10/logs/`;
  лог одной сессии — около 237 МБ.

## Решение по длине партии

Горизонт задаётся на стороне агента: партия останавливается на ходу
**N = 50** (меньше серверного лимита ~90), результат снимается на этом ходу.

## Базовая линия (без LLM)

| Игрок | Прогон 1 | Прогон 2 |
|---|---|---|
| Случайный агент | 18 | 16 |
| Встроенный ИИ (3 игрока) | 121–131 | 80–91 |

Разброс между прогонами большой → для сравнений нужны несколько партий
и фиксированный горизонт.

## Последствия

- Обновление CivRealm или его зависимостей требует проверки совместимости.
- Логи CivRealm нужно перенести в `runs/` (параметр `logging_path`).
- Валидатор действий обязателен: защищает и от ошибок модели,
  и от падения партии.
